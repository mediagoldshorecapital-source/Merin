# Worked example

A dry run of the Gem's output contract against a real copy set from prior production work.
Optional — upload it alongside `KNOWLEDGE.md` if you want the Gem anchored to a concrete shape.

Two concepts here, both transcreated from the same input, diverging on all eight differentiation
axes. The rule scales to any count.

## Input

```
Headline: Done With the 3 PM Crash
Callouts: Steadier Daily Energy / Less Afternoon Slump /
          Support for Cellular Energy / More Energy for Your Day
Body: Clean cellular support made for your daily routine.
CTA: Shop Cellular Energy
```

## Differentiation check

| Axis | 1 · Kitchen Counter Still Life | 2 · The Afternoon Split |
|---|---|---|
| Colour field | light ground, purple type | solid purple panel, reversed white |
| Human presence | none — product still life | person mid-ground, engaged |
| Crop | tight tabletop | mid-shot at standing height |
| Template · anchor | T1 · centred | T5 · straddling the split |
| Setting · time | kitchen counter · 7:30 AM | living room · 2:30 PM |
| Copy structure | symptom statement | symptom question |
| Headline shape | short declarative, 6 words | question, 5 words |
| CTA verb | Shop | Reclaim |

No row repeats. These read as two ads, not one ad twice.

*A batch built this way buys fresh impressions against a rising cost-per-thousand — it is a volume
play, not a test. Because every element moved at once, it will not say which element won. For that,
ask for ladder mode.*

### What to notice

- **The visual axes did the work.** Removing the person from concept 1 and flipping concept 2 to a
  solid purple field separates them far more than any wording change could. Two posters sharing a
  photograph are the same ad however the headline reads.
- Concept 1 **omits** the ⒝ line entirely. The rule fires on second-person assertions, not on every
  headline. "Done With the 3 PM Crash" names a moment.
- The transcreation holds the claim level. "Steadier Daily Energy" → "Steady energy, all day" is a
  restatement; "No more 3 PM crash" would be an escalation to an absolute, and a failure.
- The expression direction is explicit wherever a person appears: flat, faintly irritated, not
  smiling at camera. That register is what separates this account's winners from stock-photo warmth.
- Every prompt names the label in full, in words, **and** points at the attached reference.
- **No regulatory footer in either concept**, and both prompts close on an explicit no-fine-print,
  no-disclaimer negative. Passive omission is not enough — image models add a legal block unprompted
  because supplement advertising is full of them.
- No capsule count, no per-day cost, no review badge, no percentage discount, in either concept.
