# Working rules for this repo

## Meta Ads data requests

- When the user asks for details of a specific Meta ad account, report data for **that account only**. Never mix in, compare against, or mention data from any other ad account the login can see, unless the user explicitly asks for it.
- Default Meta ad account for this business: **2009539369903270** ("Shopify: w1rbg9wu 1767817097 business's ad account", owner business "Olia Zakharovas", currency USD). Use it whenever the user says "our account" without naming another one.
- If a request is ambiguous about which account is meant, ask before pulling data rather than listing other accounts' figures.

## Reports

- Meta Ads reports live in `reports/`.
