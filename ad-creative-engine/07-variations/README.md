## The seven transforms used

A variation is not a rewrite. It changes **one thing** so the result is attributable.

| Transform | What changes | Reads the answer to |
|---|---|---|
| **Authority swap** | Which proof layer opens the ad | Is the celebrity load-bearing, or the science? |
| **Person swap** | 1st / 2nd / 3rd person on the same claim | Does the viewer need permission to hear this? |
| **Beat extraction** | One beat of a long winner becomes the whole ad | Was that beat carrying the ad? |
| **Negation flip** | Start from the failure, not the promise | Is the category cynic a better buyer than the newcomer? |
| **Specificity crank** | Vague → an exact number, time, price | How much of the lift is precision? |
| **Claim substitution** | Red-lane claim → defensible claim, same force | Is the risky line actually doing the work? |
| **Awareness shift** | Same argument moved up or down the funnel | Where is this argument cheapest to run? |

## Compliance markers used in these scripts

- 🟢 unmarked — green-lane, write freely
- 🟡 — allowed with the stated fix applied
- ⚠️ **SWAP** — the parent winner's line was red-lane; this is the substitute of equal persuasive force. Do not revert to the original on set.
