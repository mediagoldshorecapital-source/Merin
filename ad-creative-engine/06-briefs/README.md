# Briefs

One folder per brief: `B-XXXX_<Fxx>-<Axx>-<Hxx>-<ICP>/` containing `brief.md` and
`script.md`.

Scaffold a new one:

```bash
python3 tools/new_brief.py --list                    # see the libraries
python3 tools/new_brief.py -f F01 -a A13 -k H05 -i linda -w problem -b Wild
```

`B-0001_F01-A13-H05-LIN/` is a **worked example** — a fully filled brief for the
highest-priority whitespace angle found in the competitor teardown (A13, the cost of the
lost afternoon, which appears in zero of the 31 ads analysed). Use it as the standard for
how specific a brief has to be before it goes to a creator.
