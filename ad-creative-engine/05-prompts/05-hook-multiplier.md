# Prompt — Hook Multiplier

**Attach:** the winning creative's script · its performance data ·
`02-libraries/hook-bank.md` · `00-system/icp-profiles.md`

---

A creative is winning. Extract everything reusable from it and generate the next
iteration wave.

**1. Diagnose the win — precisely**
Why is this working? Separate the contributions of: the hook line · the first frame ·
the creator/casting · the angle · the offer. Say which single element you believe is
carrying it, and what evidence in the data supports that (hook rate vs. hold curve vs.
CTR). Be willing to say "the casting, not the writing" — that's usually the answer for
Linda ads.

**2. Fifteen hook variants**
Apply all five transforms from the hook bank (person swap · specificity crank · negation
flip · stakes escalation · format transposition) to produce 15 hook lines. For each:
spoken line · frame-1 visual · OST (≤ 7 words) · archetype tag · the one variable changed
versus the original.

**3. Rank them**
Rank all 15 by expected hook rate against the target ICP, with a one-line reason each.
Mark the top 6 as the batch to shoot in one session.

**4. Body reuse**
Which *other* angles could run on this same body with only the hook and product-entry
beat swapped? List them with the specific edit required for each.

**5. Cross-ICP port**
Rewrite the winning ad for the other ICP: what changes in casting, language, proof and
CTA — and what stays identical. State honestly whether the port is worth shooting or
whether this concept is ICP-locked.

**6. Fatigue forecast**
Given current frequency and spend, when should the iterations be live to catch this
creative before it decays? What's the leading indicator to watch weekly?
