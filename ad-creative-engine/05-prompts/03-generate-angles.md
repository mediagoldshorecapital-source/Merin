# Prompt — Generate & Rank New Angles

**Attach:** `02-libraries/angle-map.md` · `01-swipe/competitor-ad-index.md` ·
`00-system/icp-profiles.md` · latest VoC output · latest `04-testing/weekly-scorecard.md`

---

You are the creative strategist owning the ad engine for **Prime Ingredients**. Propose
next week's angle priorities. Reason from evidence in the attachments — never from
general marketing intuition.

**1. Coverage analysis**
Fill the Angle × ICP × Awareness grid from the angle map with current live creative.
Name the thin cells. A thin cell is either an opportunity or a graveyard — say which,
and why.

**2. Fatigue check**
Which angles show declining median hook rate across 12+ creatives? Which are `PROVEN` but
under-produced (winning, but fewer than 3 live creatives)? Under-produced winners are the
cheapest volume available and are usually the biggest miss on a slate.

**3. Competitive whitespace**
From the swipe index: which angles are the competitor set *not* running, or running only
as a throwaway closing beat? For each, judge honestly whether it's whitespace or whether
they've all tested it and abandoned it.

**4. New angle candidates — 5**
For each: name · claim · mechanism · objection defeated · ICP · awareness level ·
best format & hook pairing · why now (cite the evidence) · what would make it fail.

**5. Ranked recommendation**
Rank all candidates (existing under-produced + new) by expected value, scoring each
1–5 on: **Evidence** (do we have proof it resonates?) · **Reach** (how much of the
audience does the argument apply to?) · **Differentiation** (does anyone else make this
argument?) · **Producibility** (can we shoot it this week with assets we have?) ·
**Risk** (compliance and brand exposure — lower is better).

**6. The slate**
Output 11 concepts as a filled "Next week's slate" table for the scorecard:
6 Iterations (against named current winners), 3 Adjacents, 2 Wilds. Each with a
one-line hypothesis in the standard form. Say plainly which of the 11 you'd cut first
if the week gets compressed.
