# Prompt Library

Five prompts that run the engine's pipeline. Paste into Claude with the named inputs
attached. Each returns output in the exact shape the downstream template expects, so the
result drops straight into a brief with no reformatting.

| Prompt | Input | Output | Cadence |
|---|---|---|---|
| `01-deconstruct-competitor-ad.md` | A competitor ad (video/transcript) | Full Phase 1–6 teardown + swipe row | Per new swipe |
| `02-mine-voc-reviews.md` | Reviews / comments / tickets | VoC bank rows + candidate angles | Weekly |
| `03-generate-angles.md` | Angle map + VoC + swipe gaps | Ranked new angle candidates | Weekly |
| `04-write-brief-and-script.md` | Format + hook + angle + ICP | Filled brief and script | Per brief |
| `05-hook-multiplier.md` | One winning hook | 15 variants across 5 transforms | Per winner |
