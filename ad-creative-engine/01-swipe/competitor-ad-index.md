**Three openings this set leaves on the table**

1. **A13 — the compounding cost of the lost afternoon.** Nobody in 31 ads reframes fatigue as a cumulative loss of hours. Every competitor sells "more energy"; none sells back the four hours between 2 PM and 6 PM, every day, for a decade. That's a bigger emotional number than anything in the set.
2. **A12 as a lead, not a tag.** Price de-anchoring against clinical NAD+ therapy appears only as a closing line. An ad whose *entire premise* is the cost comparison has never been run here.
3. **Robert at Problem-Aware.** The set serves Robert almost exclusively at Solution/Product-Aware with spec arguments. The recovery-and-strength-retention angle (A14) reaches him earlier, before he's shopping, where the traffic is cheaper.

## Adding a new ad to the swipe

1. Save the reference file/link. Note the date pulled and how long it had been running — an ad running 30+ days is a signal; an ad running 3 days is noise.
2. Run `05-prompts/01-deconstruct-competitor-ad.md`.
3. Add a row above with the format/angle/hook classification.
4. If it does not fit an existing format or hook archetype, that's the interesting case — write a new card in the library and mark it `UNTESTED`.

**Sourcing:** `ads_library_search` (Meta Ad Library) filtered to the category, sorted by
runtime. Long-running ads are the only ones worth deconstructing; everything else is
someone else's failed test.
