# Gem Name

## Primary (use this one)

```
Prime Script Forge
```

**Why this name.** Two words, no explainer clause, distinctive in a Gem list. "Prime" ties it to the brand
(Prime Ingredients / Prime Elements). "Forge" says what it does — raw material in, production-ready assets out —
and it survives being read on a phone in a sidebar.

Character count: 17. Gemini Gem names are capped at 50.

---

## Approved alternates

| Name | When to use it instead |
|---|---|
| `Prime Script Forge` | **Default.** Internal creative team, mixed use. |
| `The Bangers Desk` | If the team refers to winning creative as "bangers" and you want the Gem to feel like a person, not a tool. |
| `Prime Creative Desk` | If the Gem will be shared with agency partners or a regulatory reviewer and needs to read straight. |
| `NMN Script Room` | If you spin up separate Gems per SKU and need the name to disambiguate. |

---

## Naming rules if you clone this Gem

1. **Never** append a dash-explainer (`Prime Script Forge — Ad Script Generator`). The description field does that job.
2. Keep the name stable across edits. People find a Gem by its name in a list; renaming reads as a new tool.
3. If you build a sibling Gem for a different function (statics, email, landing pages), keep `Prime` as the first
   word so they cluster alphabetically: `Prime Static Forge`, `Prime Flow Forge`.
