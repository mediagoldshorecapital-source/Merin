# Gem Description

The **Description** field in a Gemini Gem is short, user-facing, and shown under the name. It is not read by the
model as instructions — it exists so a human picking a Gem knows what they are picking.

---

## Primary description (paste this)

```
Turns a product, pain point or angle into production-ready 9:16 video ad scripts for TikTok, Meta Reels and
YouTube Shorts — built on 16 proprietary creative frameworks, Prime's measured winner data, and the verbatim
ICP language bank. Every script ships with beat timestamps, VO, OST, B-roll direction, 5 qualifying hook
variants and a compliance ledger.
```

Character count: ~380. Gemini's description field is generous; if your build caps it shorter, use the short form.
