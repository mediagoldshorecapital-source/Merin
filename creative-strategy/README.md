# Creative Strategy System

The repeatable system for building Meta ad creative that produces measurable revenue —
written so that someone who has never built an ad can execute it at an expert level.

Built from Dara Denney's *"How I Build an Elite Creative Strategy for a Brand in One Sitting"*
and applied end-to-end to **Prime Ingredients — NMN Complex 1000mg**.

---

## The one-sentence thesis

> Creative strategy is not picking formats or copying competitors. It is **finding the gaps**
> in an ad account — unaddressed personas, unaddressed awareness levels, undiversified
> angles — and **filling them with messages mined from the customer's own words.**

Everything in this repo is machinery for doing that on a schedule.

## Quickstart: your first 10 days

If you read nothing else, do this in order.

| Day | Do this | File | Output |
|---|---|---|---|
| 1–2 | Reputation Analysis — Google p1, Amazon "Ask AI", Reddit, YouTube, press | `01` Phase 1.1 | Objection Ledger (20+ objections) |
| 2–3 | Review & Comment Mining — export site reviews, mine ad comments | `01` Phase 1.2 | VoC Bank (100+ verbatim quotes) |
| 3 | Account Gap Analysis — persona / awareness / diversity | `01` Phase 1.3 | Gap Scorecard |
| 4 | Build the Concept Grid | `01` Phase 2 | 24–40 named concepts |
| 5 | Write 12 briefs from the highest-gap cells | `templates/creative-brief.md` | 12 briefs |
| 6–8 | Cast creators, ship briefs, shoot / edit / design | `01` Phase 4 | 12 assets |
| 9 | Launch Testing campaign — **Thursday** | `04` | Live |
| 10+ | Weekly scorecard, diagnose, iterate winners 3× | `05` | Compounding |

**The single most common beginner failure is skipping Phase 1 and going straight to Phase 3.**
Ads written without the VoC Bank are guesses. Ads written from it are transcription.

## Non-negotiables

1. **No concept ships without a Concept ID.** Persona × Awareness × Pillar × Angle × Format.
   If you can't name the cell it fills, you're making an ad for no one.
2. **No hook is invented if a customer already said it better.** Mine first, write second.
3. **One variable per iteration.** Otherwise you learn nothing.
4. **Never launch a new ad set on Monday.** (Your own data: Monday is 22% below Saturday.)
5. **Compliance-check every script before shooting.** See `03` § Compliance Rewrite Table.
   A rejected ad costs a day. A banned account costs the business.

## Known gaps in this build

Two inputs were unavailable in the environment where this was written. Both are marked
inline where they matter:

- **Live product page** (`tryprimeingredients.com/products/nmn`) — blocked by network egress.
  Product facts here come from the Deep Customer Intelligence Report. **Verify current

- **Meta Ads Manager account data** — the META connector is not authorized in this session.
  The Account Gap Analysis in `02` § 5 is built from the 90-day demographic data in the
  intelligence report and is left as a **worksheet to complete in one pass** against your
