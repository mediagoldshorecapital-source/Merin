# 03 — The 12 Static Formats

Each format is a repeatable recipe. A beginner should be able to open Canva, follow the steps, and produce something that looks like a $200/hr designer made it.

**Every recipe assumes the design system in `04-design-system.md`** — canvas 1080×1350 (4:5), brand colour pulled from the label, minimum type sizes, contrast rules. Read that file once before your first build.

**Difficulty key:** 🟢 beginner (30 min) · 🟡 intermediate (45 min) · 🔴 needs an image asset (60 min+)

---

## Format 01 — The Headliner 🟢

*The workhorse. Massive headline, one clean bottle, solid block colour. Best for middle/bottom funnel and retargeting.*

**Anatomy (top → bottom):**
```
┌────────────────────────────┐
│  ★★★★★  5,128 reviews      │  ← 8% height, small trust bar
│                            │
│   MASSIVE HEADLINE         │  ← 40% height, 110–130px type
│   IN 2–3 LINES             │
│                            │
│      [bottle cutout]       │  ← 35% height, centred, shadow
│                            │
│  Buy 3 Get 3 Free          │  ← 17% height, offer bar
│  $16.66/bottle             │
└────────────────────────────┘
```

**Build steps:**
1. New Canva design, custom size **1080 × 1350 px**.
2. Rectangle covering the whole canvas → fill with the brand block colour (see palette in `04`).
3. Upload the product photo → **Edit image → BG Remover** → place centre-low. Scale so the bottle is 32–38% of canvas height. Add a soft drop shadow (Shadows → Glow, low intensity) so it doesn't look pasted.
4. Text box, top: `★★★★★  5,128 reviews` at 34px, 80% white.
5. Headline text box: pick from Framework 1, 4 or 12 in `02-copy-bank.md`. Set 118px, bold, line height 1.05, left-aligned. Highlight the payoff word in the accent colour.
6. Offer bar: rounded rectangle in accent colour, 90% width, `Buy 3 Get 3 Free · $16.66/bottle` at 46px.
7. Duplicate the page → resize to **1080×1920** for the 9:16 version; move the headline up, respect the story safe zones.

**Best headlines:** 1.1, 1.9, 4.1c, 4.4, 12.4
**Common mistake:** headline too small. If it doesn't fill 40% of the canvas, it's too small.

## Format 02 — The Comment-Frame Social Proof Ad 🟢

*A real customer review, framed like a social comment, sitting on top of the product shot. The highest-trust format for a woman who has been scammed before.*

> **Rename note:** the source material calls this the "fake comment ad." We build it with **real reviews only.** A fabricated review in an ad is unlawful under the FTC fake-review rule and is a Meta policy violation. The frame can look native; the words must be genuine. See `08-compliance.md`.

**Anatomy:**
```
┌────────────────────────────┐
│ ┌────────────────────────┐ │
│ │ ◯ Darlene M. ✓         │ │  ← comment card, white, rounded
│ │   ★★★★★                │ │
│ │   "I don't feel the    │ │
│ │   3 PM crash anymore.  │ │
│ │   I finally have the   │ │
│ │   energy to keep up    │ │
│ │   with my grandkids!"  │ │
│ │   ♡ 412   Verified     │ │
│ └────────────────────────┘ │
│                            │
│      [bottle, hero]        │
│                            │
│   Shop Buy 3 Get 3 Free    │
└────────────────────────────┘
```

**Build steps:**
1. Background: warm gradient or brand block colour.
2. White rounded rectangle (radius 32px), 88% width, top third. Subtle shadow.
3. Inside it: 64px circle avatar (use a neutral initial-circle, **not** a stock photo of a person who didn't write the review), name `Darlene M. ✓`, five gold stars, then the review at **44px minimum**.
4. Add `Verified Buyer` in small caps under the quote.
5. Bottle underneath, background removed, 30% canvas height.
6. Bottom CTA bar: `Shop Buy 3 Get 3 Free`.

**Do not:** invent like/heart counts, invent a reviewer, or use a stock headshot as the reviewer. Real name-initial and real quote, or don't ship it.

**Variants to test:** change only the review (5 reviews = 5 ads, one variable isolated).

## Format 03 — The 4-Grid Collage 🟡

*Four quadrants stop the scroll by showing four things at once. Great cold-traffic asset.*

```
┌─────────────┬──────────────┐
│             │  BRAIN FOG   │
│  [bottle]   │  & 3 PM      │
│             │  CRASHES     │
├─────────────┼──────────────┤
│ ✓ More energy│              │
│ ✓ Better focus│  [woman 60s │
│ ✓ Healthy    │   walking,   │
│   aging      │   smiling]   │
└─────────────┴──────────────┘
```

**Build steps:**
1. Draw two guides at 50% horizontal and 50% vertical.
2. **Top-left:** product on a light tint of brand colour.
3. **Top-right:** pain headline, 3 short lines, on the darkest brand shade, white text, 72px.
4. **Bottom-left:** three ticked benefits on a mid tint, 48px. Use her ManyChat words exactly: *More energy · Better focus · Healthy aging.*
5. **Bottom-right:** lifestyle photo of a woman **60–70**, Sunbelt setting, natural light. Not a model in her 40s.
6. Unify: all four quadrants must be tints/shades of the **same** brand hue. That's what makes it look designed rather than assembled.
7. Optional: 8px white gutters between quadrants for a cleaner grid.

**Common mistake:** four unrelated colours. It looks like a ransom note. One hue, four values.

## Format 04 — The Timeline Ad 🟢 *(build this first)*

*The AOV fixer. Kills "when will it work?" and makes the 6-bottle bundle the logical choice.*

```
┌────────────────────────────┐
│  How it actually feels      │
├────────────────────────────┤
│ DAY 1    Afternoon energy   │  ← band 1, lightest tint
│          holds              │
├────────────────────────────┤
│ WEEK 3   Mental clarity     │  ← band 2, mid tint
│          comes back         │
├────────────────────────────┤
│ MONTH 3  Keeping up with    │  ← band 3, full brand colour
│          the grandkids      │
├────────────────────────────┤
│  [bottle]  Buy 3 Get 3 Free │
│            6 months supply  │
└────────────────────────────┘
```

**Build steps:**
1. Three full-width bands, each ~200px tall, progressively darker in the same hue. The visual gradient *is* the progress metaphor.
2. Time marker (DAY 1 / WEEK 3 / MONTH 3) in the accent colour, bold, 52px, left column.
3. Benefit text 48px, white or near-black depending on band contrast.
4. Footer band: bottle + `Buy 3 Get 3 Free — 6 months supply — $16.66/bottle`.
5. Star bar + review count in the header.

**Copy versions A–E are all written for you in `02-copy-bank.md` Framework 3.** Build all five — it's the same file, one text edit each.

**The AOV mechanic:** explicitly write "6 months supply" next to the bundle. A 3-month promise plus a 6-month supply is what moves her off the 2-bottle option.

## Format 05 — The Instagram-Organic Story Ad 🔴

*Designed to look like an organic story from a friend. Bypasses ad-blindness entirely. 9:16 only.*

**Build steps:**
1. Canvas **1080×1920**.
2. Base image: **first-person POV photo of a 60-something woman's hand holding the bottle.** Warm indoor or patio light. Slightly imperfect framing — a phone photo, not a studio shot.
3. Overlay text using Instagram's native styling: white text on a semi-transparent rounded "highlight" background, or the classic white-with-slight-shadow. Font: a clean geometric sans (Poppins / Inter is close enough).
4. Copy in peer voice, not brand voice: *"Feeling more tired as you age? It's not just aging."* or *"3 weeks in. I'm not looking for the couch at 3 anymore."*
5. Keep everything inside the safe zone: **top 250px and bottom 340px free** of critical text.
6. Optionally add a native-looking sticker (a poll or a star rating) — but never fake a real UI element that implies engagement that didn't happen.

**The hand is the whole ad.** A 30-year-old manicured hand kills this format instantly. If you're generating it with AI, see the prompt in `05-production-workflow.md` and check: visible veins, age spots, softer skin, short natural nails, maybe a wedding band worn thin.

## Format 06 — The Breakup Letter 🟢

*Text-only, high dwell time, extremely cheap to produce.*

**Build steps:**
1. Background: cream `#F6F1E7` or a light paper texture. Nothing else.
2. Body copy in a **serif** (Lora, Playfair, Source Serif) at 48px, line height 1.5, generous margins (100px each side).
3. Use the letters from `02-copy-bank.md` Framework 9 verbatim.
4. Signature line in a handwriting font at 60px.
5. Bottom 15%: small bottle, `★★★★★ 5,128 reviews`, `Buy 3 Get 3 Free`.
6. Resist decorating. Whitespace is the format.

**Test rule:** one letter, four headline variations at the top (`Dear 3 PM,` vs `A letter to my 3 PM slump` vs `I broke up with 3 PM` vs no header). One variable.

## Format 07 — The iMessage Thread 🟡

*Two women her age texting. See Framework 10 for the scripts.*

**Build steps:**
1. White or very light grey background, iOS-style.
2. Bubbles: incoming `#E9E9EB` with dark text; outgoing `#0B84FF` with white text. Rounded 36px, with the little tail.
3. **Scale the UI up ~140% from real iMessage.** Body text minimum **40px** on a 1080 canvas. Real iMessage proportions are unreadable for a 62-year-old.
4. Contact name at top in the iOS header style. Use a first name only — *Sue*, *Barb*, *Denise*, *my daughter*.
5. End the thread on the emotional beat, not on the CTA. Put the offer in a footer bar below the phone UI.
6. Add a small brand lockup at the bottom so the ad is clearly identifiable as an ad.

**Do not** fabricate a screenshot of a real messaging app in a way that implies it's an authentic captured conversation from a real customer. Style it as an illustration — brand bar present, not a pixel-perfect forgery.

## Format 08 — The Objection Checklist 🟢

*Bottom funnel. Product beside the ticked list from Framework 11.*

**Build steps:**
1. Split canvas: left 45% product on brand colour, right 55% checklist on white/cream.
2. Ticks in the accent colour, 44px. Text 42px, one line each, max 7 items.
3. Headline across the top: *"Everything you were about to Google."*
4. Guarantee gets its own visual weight — badge or boxed line at the bottom.

**This is the single best retargeting asset in the set.** She has visited, she didn't buy, and this answers the exact reasons why.

## Format 09 — The Us vs. Them Comparison 🟡

*Two-column table. Ours ticks, category crosses.*

**Build steps:**
1. Two columns. Ours: brand colour, ticks in white or bright accent. Theirs: neutral grey, crosses in muted red-grey.
2. Header row: `NMN Complex` vs `The bottle you already tried` — **never a competitor's brand name.**
3. 4–5 rows max. Any more and she stops reading.
4. Row labels 40px, cell content 44px.
5. Winner's column gets a subtle raise: slightly larger, slight shadow, maybe a "★ Lab tested" ribbon.

**Compare against:** the category average, generic supplements, or doing nothing. Never a named brand — that's a legal exposure and a Meta policy issue.

---

## Format 10 — The Pain-Point Split 🟡

*Left = her 3 PM. Right = her 3 PM on NMN. Same woman, same chair, two different days.*

**Build steps:**
1. Vertical split. Left desaturated/cooler, right warm and bright.
2. Left label `3 PM` in muted grey. Right label `3 PM` in accent colour.
3. Same subject in both halves — an actual woman in her 60s. Continuity is what sells it.
4. Thin divider line. Headline across the bottom third on a solid band.
5. **Never present this as a clinical before/after.** No dates, no "results" framing, no implied medical outcome. It's an illustration of a feeling. See `08-compliance.md`.

## Format 11 — The Big Stat Ad 🟢

*One enormous number. Fastest-reading ad in the set.*

**Numbers you can use:**
| Stat | Line | Terr. |
|---|---|---|
| **64%** | of NMN products fail independent lab testing. Ours doesn't. | TRU |
| **50%** | Your NAD+ drops about this much between 40 and 60. | ENG |
| **5,128** | five-star reviews. Read a few. | TRU |
| **$16.66** | a bottle with Buy 3 Get 3 Free. | VAL |
| **3 PM** | The hour that changed first for most of our customers. | ENG |
| **500,000+** | customers. You would not be the first to try this. | TRU |

**Build steps:** number at 300–400px filling the top half, one supporting sentence at 52px beneath, bottle small in the corner, trust bar at the bottom. That's the entire ad.

## Format 12 — The Bundle Maths Ad 🟢 *(the AOV fixer, part 2)*

*Show the arithmetic. She is on a fixed income and she does the maths herself — do it for her.*

```
┌────────────────────────────┐
│   1 bottle      $29.98     │  ← struck through, grey
│                            │
│   6 bottles     $16.66 ea  │  ← huge, accent colour
│   Buy 3 Get 3 Free         │
│                            │
│   [six bottles lined up]   │  ← the visual abundance cue
│                            │
│   6 months. One order.     │
│   [XX]-day money back.     │
└────────────────────────────┘
```

**Build steps:**
1. Anchor price at 60px with a strikethrough, grey. Effective price at 160px in the accent colour.
2. **Show six bottles.** Physical abundance is what makes a $100 order feel like a good decision. One bottle photographed six times, spaced evenly, slight scale variation for depth.
3. `6 months. One order.` — reframes the spend as convenience, not cost.
4. Guarantee line at the bottom, always.

**This format plus Format 04 are the two assets most directly responsible for moving AOV from $55.78 to $62.** Build both in week one.

## Which format for which funnel stage

| Stage | Audience | Formats to run |
|---|---|---|

| **Warm / engaged** | Video viewers, page engagers, IG engagers | 02 Comment Frame, 06 Breakup Letter, 07 iMessage, 10 Pain Split |
| **Hot / retargeting** | Site visitors 30d, ATC 14d | 08 Objection Checklist, 12 Bundle Maths, 02 Comment Frame, 04 Timeline |
