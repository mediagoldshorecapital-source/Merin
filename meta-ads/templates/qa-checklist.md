# QA Checklist — Run Before Every Launch

**Creative:** `___________________________________`
**Checked by:** ____________  **Date:** ____________

---

## Technical

- [ ] 9:16 (1080×1920) exported
- [ ] 4:5 (1080×1350) exported
- [ ] 30fps, H.264 MP4, 8–12 Mbps
- [ ] Audio normalised to −14 LUFS, no clipping, voice clearly above music
- [ ] Captions **burned in** (not platform auto-captions)
- [ ] Caption spelling correct: **NMN**, **NAD+**, **Prime Ingredients**, **1000mg**
- [ ] Captions in the middle third, not the bottom (Reels UI covers the bottom)
- [ ] Nothing critical in the bottom 20% of the 9:16
- [ ] First frame is visually interesting (it's the thumbnail)
- [ ] The very first breath/dead beat is cut — the hook starts on frame 1
- [ ] Filename follows the convention in `03-creative-matrix.md`

## Message

- [ ] Product name, **1000mg** dose, and offer clear within the first 6 seconds
- [ ] A **specific timeframe** is stated ("around week three")
- [ ] CTA states **bundle name + per-bottle price + guarantee**
- [ ] A trust element is on screen for at least 2 continuous seconds
- [ ] Price used is **$16.66/bottle on Buy 3 Get 3 Free** — never "$58" (see README verification table)
- [ ] Only one idea in this creative
- [ ] Text is legible when squinting at a phone from 3 feet

## Compliance (`11-compliance-guardrails.md`)

- [ ] **No sentence asserts what the VIEWER is, feels, or has**
      *(search the script for: "you are", "your", "at your age", "struggling with", "feeling tired?")*
- [ ] No disease named as prevented, treated, cured, or made less likely
- [ ] Every statistic has a source in the substantiation folder
- [ ] Testimonials are real, unedited in substance, and typical of results
- [ ] Paid creator disclosed / Paid Partnership tag applied
- [ ] Any expert on camera holds the credential shown; no fake white coats
- [ ] FDA disclaimer present where claims are made
- [ ] No body before/after, no zoomed body parts, no shame framing
- [ ] Landing page makes the same claims — and no bigger ones

## Setup

- [ ] Ad name follows the convention
- [ ] UTM parameters applied
- [ ] Destination URL correct; the advertised bundle is pre-selected where possible
- [ ] Placed in the correct ad set (TESTING for new creative)
- [ ] Ad set minimum spend limit set (~1× AOV/day)
- [ ] Both ratios attached as placement-specific assets
- [ ] Primary text, headline, and description written
- [ ] First 125 characters of primary text survive truncation and still sell

## The five-second test

Show it to someone who has never seen it. Stop at 5 seconds. Ask:

> **"What's this about, and who's it for?"**

- [ ] They answered correctly

If they couldn't, the hook has failed. **Do not launch it and hope budget fixes it.** Go back and rewrite the first three seconds.

## Post-launch (within 1 hour)

- [ ] Status is **Active**, not In Review or Rejected
- [ ] Link test-clicked on an actual phone
- [ ] Landing page loads in under 3 seconds on mobile
- [ ] Apple Pay visible at checkout
- [ ] Logged in `creative-tracker.csv`
